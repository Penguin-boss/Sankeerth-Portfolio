## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Install dependencies

```bash
npm install
```

### Run in development mode

```bash
npm run dev
```

Then open:

```bash
http://localhost:3000
```

### Build for production

```bash
npm run build
npm run start
```

---

## 📝 Content Management

All portfolio data is centralized in:

```bash
src/data/portfolio.ts
```

This file controls:

- personal details
- contact links
- about section content
- projects
- skills
- experience
- certificates
- education

This makes the portfolio easy to update without changing multiple components.
